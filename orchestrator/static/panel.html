Project — every launch binds to a project: the run executes in the project's work directory (which must be the root of an existing git repository — gate commits land there, state lives in <workdir>/.orchestrator/) and carries the project's standing safeguards and defaults. When a project declares several work areas a selector appears. Declare projects with “+ Project” in the sidebar.

Goal doc — when a description doc path is set, the file's content becomes the goal, snapshotted at launch.

Strategy profile — governs the run's review depth. legacy reproduces the pre-reform flow exactly; strict / light set the doc-review threshold (what a finding must exceed to open a fix cycle vs record as tracked debt). No seed is pre-selected on purpose — the choice is explicit.

Acts — empty = family default (claude: opus-4.8/max, codex: gpt-5.5/xhigh); model options adapt to the agent; editable mid-run from the run view. Reviews stay family-rotated regardless.

Verification — left empty, the implementer reports the repo's official suite and the driver arms the gates with it.

Repoint strategy profile

Swap ≠ edit: the run points at another profile; the profile itself is never mutated. The repoint takes effect at the next stage boundary — the interpreter that honors it lands in a later phase; for now it re-labels the run's governing profile and records the operator's intent.

Project

Work directory — the git repo runs of this project execute in. Changing it (or the read-only roots) re-declares the area: the version bumps, the status returns to pending, and the next bound launch validates the real roots and confirms ready.

Read-only roots — sibling repos workers may READ for evidence (dependencies, consumers); they are never editable by workers.

Safeguards — standing law rendered into every bound worker's prompt. Version is operator intent: bump it on substance changes so runs re-record the safeguard. Run-scoped amendments win on conflict.

Defaults — a JSON object merged beneath every bound launch of this project. Configuration outlives runs; edits bind the next launch or worker call.
