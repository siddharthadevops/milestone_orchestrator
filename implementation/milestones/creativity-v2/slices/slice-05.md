# Slice 5 — Expose sparse controls and inspectable evidence

## INTENT

This slice makes the sparse Creativity search usable and understandable in
the existing operator panel. The operator sees the shared collection of ideas,
which choices a proposal uses, how many it leaves out, and the complete
assessment. Weak and invalid proposals remain useful evidence. The order form
offers the controls that actually affect a new search.

The slice owns ordering and inspection: the task catalogue, the information
returned for task details, and its presentation. Operators can still paste
search material or load a local JSON file into the same editor. Historical
tasks remain readable with their original meaning.

Dependencies are the preceding slices' admitted material, ordered active
combinations, retained evaluations and completed-run results, plus the existing
task service, staffing, accounting and panel. This slice does not change how
ideas evolve or receive scores, run a creative-quality comparison, introduce
another editor or execute proposals.

Acceptance requires working form submission and executable displays of real
task-view fixtures, with both sparse and historical examples. The main risks
are a broken material display, misleading controls, hidden paid assessments,
and presenting historical scores as unusable or a prepared result as finished.
Presentation changes are reversible; the saved work must remain intact.
